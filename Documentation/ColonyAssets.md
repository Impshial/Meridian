# Colony asset provenance

These six archives were supplied by the project owner for this implementation. Their FBX files and accompanying texture maps are retained under `Assets/_Meridian/Art/Imported`, with normalized Unity prefabs and URP materials under `Assets/_Meridian/Resources/Colony/Models`.

| Supplied archive | Project asset |
| --- | --- |
| construction_bot_2.zip | ConstructionBot |
| sci-fi+mining+drill+mecha+3d+model.zip | MiningDrill |
| space+habitat+dome+3d+model.zip | HabitatDome |
| futuristic+poser+source+machine+3d+model.zip | PowerMachine |
| futuristic+storage+module+3d+model.zip | StorageModule |
| industrial+robot+3d+model.zip | IndustrialRobot |

Imported models use normalized footprints and supplied base-color/normal maps. Their technical filenames identify conversion exports, not a verified author or license. No independent redistribution or commercial-license claim is made here; the original supplied archives remain the provenance source.

The project additionally constructs its spacecraft, ramps, boosters, foundations, ports, dome frames, covered corridors, furnishings, utility equipment, bipeds and activity effects in `ColonyModels`/`ColonyEnvironment`. Synthesized audio is generated in `ColonyAudio`. No unrelated online models or sound packs were downloaded.

The existing Meridian menu artwork, reference and fonts are preserved. See the repository README for font notices.
